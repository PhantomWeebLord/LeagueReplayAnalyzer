ReplayAnalyzer

See who controls the map — minute by minute

Pick a replay from the list above (it reads your Documents\League of Legends\Replays folder), click Open .rofl…, or drag a .rofl file onto this page. You'll get a full game review: every action graded, accuracy per player, and a map of who controlled what, when.

1Keep the League client open — the app reads match timelines from it, no setup needed (works for ranked, normals and custom games).
2Optional: for richer data on ranked/normal games (wards, item purchases, level-ups), get a free API key at developer.riotgames.com and paste it top right. Dev keys expire every 24h.
3Choose a replay. Match data is cached locally, so each game only downloads once.

Why not read positions straight from the .rofl? The replay stores the game's network packets encrypted per patch. The app reads the replay's metadata to identify the game and players, then loads Riot's official timeline (every player's position each minute, plus every kill, tower and objective).
